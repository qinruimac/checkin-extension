# 网页签到助手 (edge-checkin-extension)

一个基于 Manifest V3 的 Edge 浏览器扩展，用于便捷网页签到。支持选取页面元素自动点击签到、手工添加签到任务、批量执行所有签到任务。

## 功能特性

### 1. 快速新增签到任务（元素选择器模式）
- 在需要签到的网页上，点击扩展弹窗中的"选取签到按钮"
- 页面进入选择模式：鼠标悬浮高亮元素（红色边框），点击选中
- 选中后弹出确认浮层，可编辑任务名称，确认后保存
- 自动生成稳定的 CSS 选择器（优先使用 id，其次 class+tag，最后 nth-of-type）
- 按 `ESC` 键可取消选择模式

### 2. 手工添加任务
- 在弹窗中展开"手工添加"表单
- 填写任务名称、URL、选择任务类型（"点击签到"或"仅打开网页"）
- "点击签到"类型可填写 CSS 选择器（留空则仅打开网页）

### 3. 执行所有签到任务
- 点击"执行所有签到"按钮，显示 10 秒倒计时
- 倒计时期间可点击"取消执行"中止
- 倒计时结束后依次执行每个任务：
  - 在后台新标签页打开任务 URL（不打扰当前浏览）
  - "click" 类型且有 selector 时，自动点击对应元素
  - 每个任务之间间隔 2 秒
- 执行完成后显示结果汇总（成功/失败数及详情）
- 发送桌面通知提醒

### 4. 任务列表管理
- 弹窗主区域显示所有签到任务
- 每个任务显示：名称、URL（截断）、类型图标（🖱️点击 / 🌐打开）
- 支持删除单个任务
- 任务列表持久化存储（chrome.storage.local）

## 安装方法

1. 打开 Edge 浏览器，地址栏输入 `edge://extensions/`
2. 打开右上角的"开发者模式"开关
3. 点击"加载解压缩的扩展"按钮
4. 选择本项目的 `edge-checkin-extension` 文件夹
5. 扩展安装完成，工具栏会出现签到助手图标

## 使用方法

### 方式一：选取签到按钮（推荐）

1. 打开需要签到的网页
2. 点击工具栏中的签到助手图标
3. 点击"选取签到按钮"
4. 在页面上将鼠标移到签到按钮上（会显示红色高亮）
5. 点击该按钮，弹出确认浮层
6. 编辑任务名称（默认使用元素文本），点击"确认保存"

### 方式二：手工添加

1. 点击工具栏中的签到助手图标
2. 点击"手工添加"展开表单
3. 填写任务名称、页面 URL
4. 选择任务类型：
   - "点击签到"：还需填写 CSS 选择器（可留空）
   - "仅打开网页"：只需打开页面即可
5. 点击"保存任务"

### 执行签到

1. 点击工具栏中的签到助手图标
2. 点击"执行所有签到"
3. 等待 10 秒倒计时（可取消）
4. 倒计时结束后自动执行所有任务
5. 查看执行结果汇总

## 技术说明

- **Manifest V3**：使用最新的扩展开发规范，不使用已废弃的 API
- **chrome.storage.local**：任务列表持久化存储
- **chrome.scripting.executeScript**：动态注入 content script 执行点击
- **chrome.notifications**：执行完成后发送桌面通知
- **CSS 选择器生成算法**：从目标元素向上遍历 DOM 树，优先使用 id，其次使用 class+tag 组合，最后使用 nth-of-type 路径，确保选择器稳定且唯一
- **模拟点击**：派发完整的鼠标事件序列（mousedown → mouseup → click），同时调用原生 click() 作为兜底

## 权限说明

| 权限 | 用途 |
|------|------|
| activeTab | 访问当前标签页进行元素选取 |
| storage | 持久化存储任务列表 |
| tabs | 创建和管理标签页 |
| scripting | 动态注入 content script |
| notifications | 发送桌面通知 |
| host_permissions: `<all_urls>` | 在任意网页上执行签到操作 |

## 注意事项

- 部分网站可能有反自动化检测，自动点击可能不生效
- CSS 选择器基于添加时的页面结构生成，如果网站改版可能需要重新选取
- 执行任务时标签页在后台打开，不会切换当前标签页
- 建议在添加任务前先手动签到一次，确认签到按钮的位置和选择器
